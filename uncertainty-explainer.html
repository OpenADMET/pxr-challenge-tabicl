Uncertain uncertainties

Plotting |error| against model uncertainty and judging by Spearman rank correlation might not be the right framing. Here we separate the concepts and re-examine the evidence.

00 Calibration vs. ranking

Uncertainty estimates can answer two distinct questions. They sound similar but test different properties and can give opposite verdicts on the same model.

Calibration

Are the error bars the right width? If the model says "90% interval," do 90% of true values actually land inside it? This is a property of the population. You pool all 260 compounds and ask one question with 260 data points answering it.

Ranking / discrimination

Can the model tell you which compounds are hard? Do the ones with wider predicted intervals actually produce larger errors? This is a property of individual compounds. You need each compound's predicted uncertainty to line up with its realized error.

Calibration asks: on average, are the intervals honest? Ranking asks: for each compound, does the model know where it will be wrong? A model can pass one and fail the other.

02 The question from a commenter

Jonas Landsgesell pushed back with a toy example: a well-calibrated linear model whose Spearman ρ between predicted interval width and absolute error was essentially zero. His question:

The challenge

"I don't see exactly why you expect a strong correlation there. Did you investigate a data-generating process from which you would expect a different Spearman correlation?"

In plain terms: what if ρ = 0.26 is normal, even when the uncertainty estimates are perfectly calibrated? What if we declared the ranking bad without checking what "good" would look like?

03 Do the predicted uncertainties actually vary?

A low ρ has at least two explanations worth checking. The first is straightforward: the model might predict nearly the same σ for every compound, leaving no ranking to detect. If so, a low ρ would be expected regardless of how many measurements we had. Before looking for subtler causes, we need to check whether the σ values spread out enough to encode a ranking in the first place.

04 The one-flip problem

The σ values vary and the intervals are calibrated, yet the Spearman ρ is only 0.26. One explanation is that the Spearman ρ test, computed on individual residuals, lacks the statistical power to detect the ranking when each compound contributes only one observation. The following analogy illustrates why.

The coin analogy

Imagine each compound has a coin. Compound A's coin lands heads 60% of the time (high σ, expect large errors). Compound B's coin lands heads 40% of the time (low σ, expect small errors).

If you flip each coin a thousand times, you can easily tell which coin has the higher rate. Compound A clearly produces more heads.

But you only flip each coin once. Compound A might land tails. Compound B might land heads. From those two flips, you'd rank them backwards.

That's exactly what's happening in our scatter plot. Each compound has a predicted σ that defines a distribution of possible errors. The predicted mean is fixed; the true value is what varies. Each residual measures the distance between the fixed prediction and a single realization of the true value, and we observe only one realization per compound.

A compound with a wide predicted distribution (high σ) will, on average, produce larger residuals, but on any single occasion it might land close to the predicted mean and show a small error. Wide distributions still produce values near their center.

So we're trying to correlate a property of a distribution (its width) with a property of a single sample from that distribution (how far that one sample landed from the center). With one sample per distribution, the rank correlation is weak, even when the uncertainty estimates are correct.

A synthetic toy example illustrates the mechanics. Using our actual 260 predicted σ values, we simulate a perfectly calibrated model and ask: what Spearman ρ would we observe if we could measure each compound not once but n times, averaging the absolute residuals over replicates? At n = 1 (our real situation), ρ averages 0.28. By n = 3 it reaches 0.49. By n = 10, 0.72. More replicates average out the noise in individual draws, letting the ranking emerge.

This simulation draws residuals from the model's own predicted σ values, which means it assumes those σ values are correct. That assumption is partially validated by the calibration plot (miscalibration area 0.04), but it is not an independent proof. The simulation demonstrates the mechanics of the one-flip problem (one draw per compound limits ρ even when the ranking is real) rather than proving that our model's specific σ values are right. It also ignores real-world complications: experimental noise in the labels, non-Gaussian error distributions, and the fact that replicate measurements in a real assay would introduce their own sources of variability beyond what a simple Gaussian captures.

05 What does perfectly calibrated uncertainty produce?

The replicate curve in section 04 showed that more measurements per compound would strengthen ρ toward 1 by varying the number of draws per compound. This section takes the complementary approach: holding the replicate count at 1 (matching our data), it asks what distribution of ρ values a model with ideal uncertainty estimates would produce. Section 04 asked how many measurements it would take to see the ranking clearly; this section asks whether ρ = 0.26 indicates a ranking deficiency or is simply the expected outcome given one measurement per compound.

We take the 260 predicted σ values from the real model and pretend the uncertainty estimates are perfectly calibrated: for each compound, we draw a single residual from a Gaussian with that compound's σ. The point predictions can still be wrong (they are); what's "perfect" is only the error bars. We compute Spearman ρ on those simulated residuals and repeat 2,000 times to build a distribution of ρ values.

To be precise: "perfectly calibrated" here means each compound's true error really is drawn from the Gaussian the model prescribes. The model is not making perfect predictions (zero error). It is making imperfect predictions and correctly estimating how imperfect each one is. If our observed ρ = 0.26 falls inside that distribution, the low correlation reflects the measurement setup (one residual per compound) rather than a deficiency in the model's uncertainty. If it falls below, there's a real ranking problem the measurement noise cannot explain.

06 The result

Perfectly calibrated uncertainty with our σ distribution produces a mean Spearman ρ of about 0.285. Our observed 0.26 sits at the 34th percentile of the null distribution, well within the 95% interval of [0.17, 0.40]. The ρ we observe is what we would expect even if the uncertainty estimates were ideal. The low correlation reflects the inherent noise of comparing a distribution's width to a single sample from it.

The blog post's conclusion, "not a reliable ranking of which compounds are hard," is too strong. The σ values vary, calibration holds, and higher σ does correspond to higher expected error, so the ranking is present. Any test based on individual residuals will show a weak correlation, because each residual is one noisy draw from the distribution it's being compared against.

07 What this means in practice

The calibration plot (Figure 6 right in the blog post) already told us the intervals are the right width. The σ distribution tells us the model differentiates between compounds. Together, those two facts mean the uncertainty estimates are useful.

What you can do with them: use the predicted intervals directly. If compound A has a 90% interval of [4.5, 6.5] and compound B has [5.0, 5.4], pick B when you need precision. Over a portfolio of decisions, calibrated intervals with real σ variation will outperform ignoring them.

What you can't do: look at one compound's error after the fact and judge whether the model "knew" it was hard. That's the one-flip problem. Confirming the ranking for any individual compound would require repeated measurements, but across a batch the ranking holds.

The reliability diagram in section 01 already showed calibration passing. Several evaluation tools may handle the ranking question better than Spearman ρ on individual residuals, though each comes with its own assumptions and limitations. The first two (quintile binning and CRPS) address compound-level enrichment directly. The third (NLL) is an aggregate model-comparison metric that does not support enrichment. The fourth (conformal prediction) is a method for producing intervals with coverage guarantees, rather than an evaluation tool.

The one-flip problem limits every evaluation tool that follows. Each method works around it (by aggregating, by scoring the full distribution, by testing calibration globally), but none eliminates it. Replicate measurements would sharpen all of them: more observations per compound would reduce the noise in per-compound error estimates, tighten the quintile bins, widen the gap between variable and constant σ in CRPS and NLL, and push the Spearman ρ curve from section 04 toward its asymptote. The evaluation tools below are the best we can do with one measurement per compound.

07a Quintile binning

The simplest approach: sort the 260 compounds by predicted σ, split them into five equal groups (~52 each), and compute the mean |residual| in each bin. Pooling 52 compounds per group averages out the single-draw noise that makes the raw scatter plot so cloudy. If the ranking is real, mean error should increase across the bins.

Quintile binning: mean |residual| by predicted σ group
Mean |residual| increases from 0.27 in the lowest-σ group to 0.65 in the highest. The ranking is real; pooling compounds per bin reveals the trend that individual residuals obscure.

Strengths: Easy to compute and interpret. Answers the ranking question directly, without modeling assumptions. Weaknesses: The number of bins is arbitrary (5 here, but 4 or 6 would give a slightly different picture). Discretizing throws away information about the shape within each bin, and the approach gives no single comparable score to rank one model's uncertainty against another's.

07b Continuous ranked probability score (CRPS)

CRPS evaluates the full predicted distribution against each observed value. It measures the area between the predicted cumulative distribution function (CDF) and a step function at the observed value. A prediction that concentrates probability near the true value scores well; one that spreads probability away from it scores poorly. Lower is better.

CRPS is a proper scoring rule, meaning a model scores best by reporting its true beliefs. It jointly rewards calibration (intervals the right width) and sharpness (intervals as narrow as possible while remaining calibrated). A model that predicts wide intervals for every compound will be calibrated but not sharp; CRPS penalizes the unnecessary width.

The decisive test: does the model's per-compound σ variation help, compared to assigning every compound the same global σ (the mean, 0.54)?

Strengths: Uses the full predicted distribution, as opposed to a point estimate. Proper scoring rule (a model minimizes CRPS by reporting its true predicted distribution, so there is no incentive to distort the estimate). Works per-observation without binning. Produces a single comparable number across models. Weaknesses: Less intuitive than "did the true value land in the interval?" Requires the full predicted CDF (or a closed-form assumption, as with the Gaussian here). Can be dominated by a few large-error outliers.

07c Negative log-likelihood (NLL)

NLL answers a different question from the first two tools. Where quintile binning and CRPS ask "can the model rank which compounds are hard?", NLL asks "how good is the model's probabilistic prediction in aggregate?" It is a model-comparison metric, not a compound-level triage tool.

Under a Gaussian prediction with mean μ and standard deviation σ, NLL = 0.5 × log(2πσ²) + (y − μ)² / (2σ²). The first term penalizes wide intervals (wasted probability); the second penalizes narrow intervals that miss the true value. Lower is better. NLL is a proper scoring rule, and compared to CRPS, it penalizes overconfidence more harshly: a single observation far outside a narrow interval produces a very large NLL, because the squared residual is divided by a small σ².

Per-compound σ beats constant σ by 3.4%, a slightly larger margin than CRPS, confirming that the variable uncertainty adds value as a whole. Unlike CRPS, NLL per quintile is not monotonic: Q1 scores best (0.32), but Q2 and Q3 score worse than Q4. This happens because NLL penalizes both directions. A moderate-σ compound with one large residual (a bad single draw) gets hammered by the (y − μ)² / σ² term, while a high-σ compound with the same residual absorbs it more gracefully. This non-monotonicity means NLL cannot be used for enrichment: sorting compounds by NLL would not reliably separate easy from hard predictions.

Strengths: Proper scoring rule. The strictest aggregate test of whether σ matches the actual error distribution. Standard in probabilistic modeling; directly optimized by many training procedures. Useful for comparing one model's uncertainty against another's. Weaknesses: Does not support enrichment or compound-level triage (non-monotonic per quintile). Heavily influenced by outliers (a single large residual against a small σ dominates the average). Assumes a distributional form (Gaussian here). Harder to interpret than CRPS or binning in absolute terms.

07d Conformal prediction

Conformal prediction is not an evaluation tool but a method for producing prediction intervals with a finite-sample coverage guarantee. Given a calibration set, it computes nonconformity scores (how "unusual" each observation is relative to its prediction) and uses their distribution to construct intervals. If you ask for 90% coverage, conformal prediction guarantees that at least 90% of future observations will fall within the intervals, with no distributional assumptions required, provided the calibration and test data are exchangeable (drawn from the same distribution, with no distribution shift between calibration and deployment).

This guarantee is marginal: it holds on average across all compounds, not for each compound individually. Standard conformal prediction assigns the same interval width to every compound. Adaptive variants (locally-weighted conformal prediction, conformal quantile regression) adjust the width per compound by scaling the nonconformity score, producing wider intervals where the model is less certain. These adaptive methods could wrap our TabICL predictions to provide coverage guarantees on top of the model's existing uncertainty estimates.

Conformal prediction does not solve the one-flip problem. Even with perfectly calibrated conformal intervals, the Spearman ρ between interval width and individual |residual| would be weak for the same reason we have been discussing: one observation per compound is not enough to reveal the ranking. What conformal prediction does offer is a coverage guarantee that requires no assumption about the error distribution (unlike the Gaussian assumption in CRPS and NLL), which makes it a useful complement when the distributional form is uncertain.

Strengths: Distribution-free coverage guarantee (under exchangeability). No model retraining needed (applied as a post-processing wrapper). Adaptive variants produce per-compound interval widths. Weaknesses: Marginal coverage, not conditional (the guarantee is across all compounds, not for each one). Requires a held-out calibration set, reducing the data available for training. Does not address the ranking question on its own; it calibrates interval widths but does not evaluate whether those widths track difficulty.
